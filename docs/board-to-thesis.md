## What still holds

- A story is not a thesis. Do not copy a Narrative card and rename it.
- Macro drafts. Nathan keeps. Auto-keep is a bug. Silence is not a keep.
- Seeing is not keeping. Correlation without a shared call mints junk.
- Clock is a **tag**, not its own column.
- Notebook first. The notebook can stop a mint. It cannot authorize one.
- Invert: name what would make the call false. (The old file said “kill.” Do not write that word on cards.)
- Already in the price, or not checked. A fake priced line is a bug.
- Sit is a real output. Few live theses.
- Do not frame cards as “money is easy / money is tight.”
- Do not write holds or names inside the Board → draft conversion.
- Do not publish the live local board.

## What the 15 August session changed

| Old slice (PR 4) | Now |
| --- | --- |
| A thesis is “one situation” | A thesis is a **judgement**: a forward-looking call or opinion. Not a mechanism, not a fact, not “how something works.” “One situation” remains a writing gate (do not collage). It is not the definition. |
| Two thesis columns on the live page, question left open | One **Theses** column. Clock is a tag: `now`, `6–12 months`, `next year`. |
| Column “Thesis candidates” = the hold | Column **Investment Ideas**. Macro writes them after a keep. Not names. |
| Conversion stops at the draft | After a keep: ideas from that thesis alone, then a **full fork** against every other live thesis. Then notebook. Then refine ownership. |
| Fights left as an open question | Tension note on the new card: we notice, they may or may not contradict, we think ____. Ideas write every live branch. Do not pick a winner. |
| One draft per pass left open | One **process** per morning (8am Hong Kong, all seven days). As many drafts as are actually new, then a **written duplicate-stop**. |
| Notebook proposed as `docs/thesis-notebook.md` in this repo | Notebook lives **with the local board**. Do not publish it here. |
| Micro begins at the hold | Micro writes **2–4 discussable names when a new Investment Idea lands**. Forced. Not “only if asked.” A thesis keep is not the trigger. Macro owns ideas. |
| “Kill / dies / desk skew” in the run voice | Plain English only. See [`standing-rules.md`](standing-rules.md). |
