# Board to thesis — not this step

**Do not run this file as intake.**

Board intake is [`board-intake.md`](board-intake.md). Stories stay stories. Do not mint a thesis here.

The old playbook (PR 4, `cursor/board-to-thesis-playbook-f7dc`) was one slice: cooked Board → thesis **draft**. PR 5 superseded that slice as the daily run (`docs/thesis-daily.md` on `cursor/funnel-board-workflows-2ab1`). Both assume the Board already grew.

It did not. Fresh prints were folded onto old cards. That is why intake exists, and why a reprint of yesterday’s list is a failed run.

If you are about to draft a thesis, stop. Grow the Board first. Then, and only then, open the later thesis file.
