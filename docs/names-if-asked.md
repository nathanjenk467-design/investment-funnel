# Names — only if Nathan asked

Micro runs this. Macro does not. Architect carries the ask.

If Nathan did not ask, **stop**. A keep of a thesis is not an ask. A finished Investment Idea is not an ask. A crowded column is not an ask.

Macro stays silent toward Nathan. Micro stays silent toward Nathan.

---

## What this is

A name is a company or instrument on the **Candidates** tab. It is a way to sit with an idea that already exists. It is not a buy. It is not a new thesis.

Micro owns names. Macro owns ideas.

If the sibling spec `docs/fundamental-momentum.md` is on the branch you are using, use it as the **name screen** (how the business makes money, what the customer cannot leave, tape agreeing or already spent). Write the card in the language in [`standing-rules.md`](standing-rules.md): “what would make this false,” “already in the price or not checked.” Do not put shop slang on the card.

If that sibling spec is not present, the gates below are enough to refuse a bad name. They are not enough to invent a trading system. Do not invent one.

---

## Gates before a ticker is written

All five, or the name stays unwritten.

1. Nathan asked, in words Architect can quote.
2. A parent thesis is live (`TH-*` Nathan kept).
3. A parent Investment Idea is written (`IDEA-*`). If the honest sit is a pair-branch, the name inherits **that branch**, not a mash-up of both theses.
4. This name is a vehicle for *that* idea. If you need a new sentence that is not the idea, you do not have a vehicle. You have a new story. Hand the story back to Macro as a Board observation. Do not invent a parent.
5. You can say how the name makes money, and how this name can be a bad sit even if the thesis is true.

A thrown name that fails gate 4 is refused. It does not get a new thesis invented for it.

---

## What a name card writes

Ordinary sentences. No ticker soup beyond the one name you can stand behind.

- Parent idea and parent thesis (and the pair-branch, if any)
- The name
- How it makes money
- How this name can be a bad sit even if the thesis is true
- Whether we actually understand it, or it is too hard
- Already in the price, or not checked
- What would make us leave this name (inherited from the idea, or a written reason it does not transfer)
- Disposition: unfinished / wait / refuse
- **Not a buy**

If several names would be one bet, say they are one bet. Do not write eight rows of the same factor.
