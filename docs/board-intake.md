# Board intake

Run at the start of the day, and whenever a cooked Board handoff arrives.

This is a read. It is not a thesis pass. It is not a live pull of Narrative.

---

## What the Board is

The Board is a **cooked Narrative handoff**.

It already holds:

- kept situations
- open calls
- housed stories
- observations
- fresh prints that update something already there

It is not a live feed. Macro does not scrape, refresh, or “pull the universe” as this step. If the cooked handoff is not on the local board, Architect puts it there. Macro waits.

A story on that Board is not a thesis. Nearby pictures are not a replacement for a judgement.

---

## Who does what

**Architect** writes the cooked items onto the local board (`index.html` + `board.json` on the local machine only). Never publish those files here.

**Macro** reads the whole Board before drafting. Macro does not add a Board card “because a print agreed.” An agreeing print sits on the theme or the story it already belongs to.

**Micro** does not touch the Board.

---

## How to read it (every item, once)

For each Board item, mark one job in words. Not a score.

| Job | Meaning | What happens next |
| --- | --- | --- |
| **Already a live theme** | Same force as a kept thesis | Sit the print on that thesis. Not a new card. |
| **Candidate judgement** | Might be one forward-looking call | Goes to [`thesis-daily.md`](thesis-daily.md) |
| **Story / observation** | True enough to house; not a call | Stays on the Board |
| **Fight** | The problem is agreed; the path is not | Stays a fight until the world picks. Do not “resolve” it into a parent thesis. |
| **Neighbor** | Near a candidate; different print would make it false | Write it down so you do not join it in a title later |
| **Noise** | Tape wiggle, slogan, reprint | Leave it. Do not draft from it. |

Do not draft in this file. Do not grab in this file. Do not write an Investment Idea.

An open call can be evidence for a candidate. It is not a thesis by itself.

---

## What intake must not do

- Do not copy a Narrative card onto Theses.
- Do not collapse two Board items into one sentence because they share a newspaper word.
- Do not treat “several cards about the same week” as one judgement.
- Do not mint a new Board card only because a print agreed with a situation already there.
- Do not run the daily tape pack inside intake.
- Do not paste the live Board into this repo or into a notebook that will be published.

---

## Hand-off

When every item has a job:

- If nothing is a candidate judgement, and no live thesis needs refine, write that in the day’s working notes and go to [`thesis-daily.md`](thesis-daily.md) anyway — the daily pass still owes a **written duplicate-stop** or a sit.
- If something is a candidate judgement, take that short list into [`thesis-daily.md`](thesis-daily.md).
- If a live thesis’s world moved, also open [`refine.md`](refine.md). Refine is not intake, and it is not a new mint.

Then stop this workflow.
