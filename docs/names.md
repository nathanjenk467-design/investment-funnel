# Names — when a new Investment Idea lands

Micro runs this. Macro does not. Architect carries the trigger: **a new Investment Idea just landed on the Funnel.**

A keep of a thesis is **not** names by itself. Do not run this file because Nathan kept a `TH-*`. Run it because an `IDEA-*` is now on the Funnel.

Macro stays silent toward Nathan. Micro stays silent toward Nathan.

---

## The standing trigger

Whenever a new Investment Idea lands, Micro **must** put **2–4 discussable names** on the Candidates tab for that idea.

Each new `IDEA-*` is its own trigger. A four-branch grid is four triggers. Do not collapse them into one name set.

Discussable means you can talk about the name. It is not a buy. It is not a live book entry.

An idea that is **sit off** (we stay off this sit) still gets names. Those are **stay-off names**: the names people would sit with if they took this sit, written so the desk can discuss staying off them.

An **honest empty** (no names on the Candidates tab for this idea) is allowed **only with a why**. Write the why on the idea’s name slot. “Nothing came to mind” is not a why. “Every obvious name is the same one bet, and a second name would be a lie” can be a why.

---

## What this is

A name is a company or instrument on the **Candidates** tab. It is a way to talk about an idea that already exists. It is not a buy. It is not a new thesis.

Micro owns names. Macro owns ideas.

If the sibling spec `docs/fundamental-momentum.md` is on the branch you are using, use it as the **name screen** (how the business makes money, what the customer cannot leave, tape agreeing or already spent). Write the card in the language in [`standing-rules.md`](standing-rules.md): “what would make this false,” “already in the price or not checked.” Do not put shop slang on the card.

If that sibling spec is not present, the gates below are enough to refuse a bad name or to write an honest empty. They are not enough to invent a trading system. Do not invent one.

---

## Gates before a ticker is written

All four, or write an honest empty with a why.

1. A new parent Investment Idea has landed (`IDEA-*`). If the honest sit is a pair-branch, the name inherits **that branch**, not a mash-up of both theses.
2. A parent thesis is live (`TH-*` Nathan kept).
3. This name is a vehicle for *that* idea — or, on a sit-off idea, a stay-off name for that idea. If you need a new sentence that is not the idea, you do not have a vehicle. You have a new story. Hand the story back to Macro as a Board observation. Do not invent a parent.
4. You can say how the name makes money, and how this name can be a bad sit even if the thesis is true.

A thrown name that fails gate 3 is refused. It does not get a new thesis invented for it.

Nathan does not have to ask. The idea landing is the ask.

---

## How many

Write **2, 3, or 4** names per new idea.

Fewer than 2 is an honest empty: write the why, write no `ST-*`.

More than 4 is a tour. Stop at 4. If several names would be one bet, say they are one bet and do not pad the count with cousins.

---

## What a name card writes

Ordinary sentences. No ticker soup beyond the one name you can stand behind.

- Parent idea and parent thesis (and the pair-branch, if any)
- The name
- Sit-with or stay-off
- How it makes money
- How this name can be a bad sit even if the thesis is true
- Whether we actually understand it, or it is too hard
- Already in the price, or not checked
- What would make us leave this name (inherited from the idea, or a written reason it does not transfer)
- Disposition: unfinished / wait / stay-off / refuse
- **Not a buy**

---

## What Micro must not do

- Do not mint a `TH-*`.
- Do not write an `IDEA-*`.
- Do not speak to Nathan.
- Do not write names because a thesis was kept and no idea has landed.
- Do not skip names on a sit-off idea. Stay-off names still go on the Candidates tab, unless you write an honest empty with a why.
- Do not leave the Candidates tab blank for a new idea with no why.
- Do not write a second reason to keep a name after the first reason went away.
- Do not treat a famous company as a bet because it is famous.

---

## After names are written

Architect places them on the local Candidates tab only.

Macro writes the notebook: which idea landed; which names Micro wrote, or the honest-empty why. Nathan’s words if he spoke.

No size. No order. No book entry from this file.
