# Notebook

Macro writes it. Architect stores it **with the local board**, not in this public repo.

Later drafts read the notebook first ([`thesis-daily.md`](thesis-daily.md) step 0).

The notebook can **stop** a mint. It cannot **authorize** one.

---

## Where it lives

A local file next to the local board. Architect chooses the exact path on that machine.

Do not publish notebook contents to this repo. Do not paste Nathan’s reasons into a public pull request.

If the file does not exist yet, Macro says “notebook empty” and continues. Do not invent past keeps to fill it.

---

## When to write

After every morning pass, and after every time Nathan answers.

Write when:

- a draft was offered
- Nathan kept, folded, parked, or sat
- a duplicate-stop was written
- a join-to-theme happened
- a refine pass saw a world print that would make a thesis false
- Nathan asked for names, or refused names
- Nathan said “this is not a thesis” or “this sits on TH-__”

Do not write Macro’s unused slogans. Do not write tickers. Do not write a why Nathan did not say.

---

## What an entry contains

Dated. Hong Kong date. His words first.

1. **What was on the table** — one-line judgement offered, or “sit, nothing offered,” or “duplicate-stop.”
2. **What Nathan kept** — quoted. If he kept nothing, say so.
3. **What he dropped** — quoted. Write a no as carefully as a yes.
4. **Why, in his words** — quoted, or plainly restated only if he asked you to tidy the sentence.
5. **If he did not say why** — write: “He did not say why.” Stop. Do not invent a why.
6. **Join instructions** — “this print sits on the plants theme”; “this is not a thesis.”
7. **Open fights he left on the Board** — so a later pass does not “resolve” them.
8. **Ideas written after a keep** — one line per `IDEA-*`, including each pair-branch. He has not been asked to pick a branch unless he said so.

---

## How a later draft reads it

Before any new judgement:

1. If he kept a theme, today’s agreeing print joins that theme. You may refresh the evidence line for him to accept. You do not mint a new id.
2. If he folded a theme, you need a new fact that answers **his** reason. A new adjective is not a new fact.
3. If he said “not a thesis,” that sentence is a shop fact. It outranks association, resonance, and a prettier title.
4. If he sat, you may offer again only if the Board changed.
5. If he did not speak, yesterday’s draft is still a draft. It is not live.

The keep already happened. You do not keep it again from the notebook.

## What the notebook is not

- Not a second Board
- Not a source of live theses
- Not a correlation map
- Not a list of tickers
- Not a license to edit a kept thesis so the old claim disappears
- Not a public file
